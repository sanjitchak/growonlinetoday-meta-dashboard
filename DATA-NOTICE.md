# GrowOnlineToday 4X ROAS VSL dashboard source

This folder contains the generated separate static dashboard built from `template/growonlinetoday-4x-roas/`.

- Advertiser: GrowOnlineToday
- Audience: coaches with proven offers using Meta ads and a VSL or booked-call funnel
- Creative direction: diagnose the path from ad click through VSL, qualification and website scheduling while optimizing toward a 4X ROAS target
- Result label: Website schedule
- Cost per result: INR 745 on every row
- Creatives: six original 1254 x 1254 planning assets
- Campaign behavior: non-draft campaigns are locked On in this local browser simulation

The IDs and performance rows are synthetic local planning data because no Meta report export was supplied. They must not be presented as live or historical account performance. The website positioning and brand colors were reviewed from `https://www.growonlinetoday.com/`; the source logo was downloaded from that site. The generated creative artwork is not an exported Meta asset. The always-on campaign setting does not connect to or modify a real Meta account.
